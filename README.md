- User-provided Arctic Pulse logo and northern photography included locally
- WebP versions generated for improved image loading

## Launch checklist
1. Replace the placeholder clinic phone number, email, exact address, and operating hours.
2. Connect the Contact / Booking form to a secure booking platform or backend. The current form is a front-end demonstration and intentionally does not transmit health information anywhere.
3. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
4. Add real social media profile URLs.
5. Have the clinic review and finalize privacy, cancellation, payment, insurance, consent and accessibility language.
6. If the clinic uses Jane, Cliniko, Noterro or another booking system, update every `contact.html#book` CTA to the official booking URL.
7. Test all content for professional-scope and jurisdiction-specific compliance before publishing.

## Deploy
Upload the contents of this folder to the web root (`public_html`, Cloudflare Pages, Netlify, GitHub Pages, etc.). Open `index.html`.
